# Фотографии

Все фотографии уже распределены по папкам:

- `hero/` — интро
- `couple/` — Дима & Даша
- `dasha/` — Даша
- `family/` — семья
- `sonya/` — Соня
- `nastya/` — Настя
- `gallery/` — фотоальбом (все 25 снимков)
- `finale/` — финальный кадр

Чтобы заменить фото — просто перезапишите файл с тем же именем и обновите страницу.

Пути настраиваются в `src/data/photos.js`.
